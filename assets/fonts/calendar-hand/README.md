# Calendar annotation font

Based on 清松手寫體8 / JasonHandwriting8 (隨性), by 游清松 / Jason (Yu Ching Sung). Licensed under SIL Open Font License 1.1; see OFL.txt.

Original project: https://github.com/jasonhandwriting/JasonHandwriting
Source font description: https://www.maoken.com/freefonts/24657.html
WOFF2 split source: https://img.maoken.com/webfont/24657/Regular/24657-Regular.css

The split WOFF2 files preserve glyphs and original copyright records. Their modified family name is SmallBarCalendarHand to distinguish this derived web distribution from the original font. No TTF or ZIP bundles are included. font.css retains Unicode ranges so browsers fetch only the parts needed for visible calendar annotations; dates, digits, weekdays and other UI text use their existing fonts. Missing glyphs fall back to the UI serif font.
