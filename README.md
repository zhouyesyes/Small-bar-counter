# Small Bar（小吧台）

> 11/9 她说：**先不实装**，样子和功能都往下做，差不多了再一起写代码。代码就写在这个仓库（吧台）里。

SillyTavern 前端扩展：从屏幕左边探头的像素小猫，点开是一列卡片（此刻、动态、小手机），小手机是弹出来的小窗。

- 一个扩展装好就能用：提示词写在扩展里，不要世界书、不要正则、不要酒馆助手脚本
- 手机优先：抽屉从左边滑出、小手机是小窗，不铺满屏幕；不用滑动手势（会碰到网页的返回）
- 黑白、极简、ins 风，浅色深色两套

**现在还在定样子，没开始写代码。** 定下来的东西见 [docs/design.md](docs/design.md)，接下来要做的见 [docs/todo.md](docs/todo.md)，样子图在 [docs/mockups/](docs/mockups/)。

玩法参考了别人的「Rainday · 随身桌面」，代码和提示词都自己写，不照搬。

## 怎么装（0.1.0 第一版）

1. 酒馆里点上面一排的 **扩展**（三个方块的图标）→ **安装扩展**
2. 粘贴这个地址，点安装：`https://github.com/zhouyesyes/Small-bar-counter`
3. 装好后刷新一下酒馆网页。屏幕左边会探出一只像素小猫，点它就打开
4. 以后更新：扩展列表里「小吧台」右边点更新，再刷新

用之前：打开一个**单人聊天**（群聊先不支持）；让他回一次，状态、动态、日记才会出来。

## 第一版有什么

- 小猫入口（只能点，不会滑）；抽屉：头图（跟天气 / 固定一张 / 他来挑）、头像名字签名、底下四个标签
- 动态：他的最新三条，点赞、留言、「让他回」；下面是他在听的歌（播放和搜歌还没有）
- 此刻：在哪、穿着、想要、心声翻面、备忘录
- 日记：最新一篇 + 以前的，喜欢、小纸条、复制、删除（只在小吧台里藏起来）
- 小手机：主页；微信（聊天：连发几条点 ↑ 他才回、他一条条出来、长按编辑删除、＋ 表情 / 语音 / 图片 / 转账 / 重生成；通讯录；朋友圈：能看到别人的、往下滑加载更多）；X（他的主页和帖子）；日记、备忘录、相册、音乐；设置
- 抽屉上点 TA 的头像可以直接换
- X 私信：你用匿名小号（可以开好几个、改网名），TA不知道你是谁，可能已读不回、拉黑你；你也能拉黑TA
- 回复时带什么（设置里，默认「自己挑」：不带预设，角色卡、人设、世界书、此刻、最近 6 楼正文都带）：「整套」交给酒馆拼（预设 + 世界书 + 角色卡 + 人设 + 剧情，只有跟正文时能选）；「自己挑」勾角色卡、我的人设、世界书（只带这次触发的条目）、此刻状态、最近正文几楼、手机聊天几条
- 小手机用哪个 API：跟正文 / 自己填一个（地址、密钥、模型，可测连接拉模型）。不接「酒馆你害我不浅」的钥匙本（她 11/9 说那边自己就能往任何地方填）
- 回复时带什么的页面上算 tokens：这一次大约多少，分角色卡、世界书、正文、手机聊天……
- 此刻簿：每一轮的此刻一页（含备忘记下 / 做完），在此刻页右上角「此刻簿」翻
- 触发（参考 Rainday）：正文顺带写；小手机每回一次消息也顺带更新（没开省一点时）；她自己点：动态「让TA现在发一条」、日记「让TA现在写一篇」、X「让TA现在发一条」、此刻「刷新此刻」。不在正文里写的状态段存在聊天数据 `small_bar.blocks` 里
- 朋友圈、TA 的 X、我的 X 各有自己的背景（右上「换背景」），没传就跟抽屉头图一样
- 微信先进通讯录，点 TA 再进聊天；现代的聊天页和真微信一个颜色（灰底、白气泡、她的绿气泡、两边方头像）；去掉了「我」那页
- 朋友圈页上直接改背景、头像、名字、签名；「刷新朋友圈」一次刷 5～8 条认识的人发的
- 音乐（`src/music.mjs`，参考 QuietRoom 的做法自己写的）：搜歌名 / 歌手、贴网易云链接或 ID 加歌；歌单（存在扩展设置里，不跟聊天走）；播放、上一首下一首、顺序 / 单曲 / 随机、拖进度；滚动歌词；「TA在听《…》· 放这首」一点就搜来放。歌来自第三方公开的 Meting 接口，6 个节点一起问谁先回用谁；放歌时一串来源按顺序试（照 QR 的做法）：搜歌带来的直链 → GD 音乐台 → 6 个 Meting 节点挨个试，只有 30 秒试听的也换下一个；网易云搜不到或放不了，再去 QQ 音乐（vkeys 接口，参考 Rainday）找同一首；都不通时放不了
- 微博（`微博:` `热搜:`）：热搜 + 广场，随随便便、吃瓜、磕 CP，不放账号；「刷新」一次来 8～10 条热搜 + 5～8 条微博
- 各个地方分开语气：朋友圈 = 熟人、体面的日常；X = 私人、夜里、不能说的那一面；微博 = 公开广场、随便
- 相册（`照片:`）和备忘录也能刷新；小手机主页右上「全部刷新」一次请求把此刻、备忘、朋友圈、X、热搜、微博、照片都更新
- X 小号能删（私信右上 ··· 或我的主页「删号」），这个号的私信、帖子一起删
- X：首页（这个世界的信息流，「刷新」一次 5～8 条，`推文:`）/ TA的主页 / 我的主页 / 私信；主页上网名、@账号、签名点了就改
- X 底下三格：TA的主页 / 我的主页（你当前的匿名号：换头像、换号、发帖）/ 私信
- 设置：头图、他的名片、我的名字头像、小手机用哪个 API（跟正文或「酒馆你害我不浅」钥匙本里的一条）、省一点、时代、提示词、手机聊天记几条、外观、小猫开关和高度
- 时代：自动猜，现代 / 民国 / 古风。三个时代页面都一样全，只换成那个年代的东西：小手机 → 信匣 / 书匣，微信 → 信笺 / 书信（聊天是信纸），朋友圈 → 副刊 / 题壁，X → 小报 / 榜文，私信 → 读者来信 / 匿名书，音乐 → 留声机 / 琴谱……
- TA什么时候回（设置）：马上回（单独请求）/ 下一轮正文顺带回（写进注入，TA在状态段里用「微信:」回）
- X 上TA和你的头像跟微信分开（点头像换），点网名就能改；此刻的本子里心声能翻面

## 它怎么工作（给以后来改的人）

- 每轮在正文提示词最后加一段（`src/prompt.mjs`），让他回完正文另起一行写 `<!--SB … SB-->` 状态段
- 收到回复后（`index.js` 的 `absorb`）把这段从正文里剪掉，存到这一楼的 `extra.small_bar`；网页上看不到，下一轮也不会带进上下文。删楼、换页、重新生成都跟着变
- 她在小吧台里做的事（留言、点赞、小手机聊天）存在这个聊天的 `chat_metadata.small_bar`
- 全局设置（API、外观、小猫位置、提示词）存在酒馆扩展设置 `small_bar` 里
- 头图、名片、时代跟着聊天走，存在这个聊天的 `chat_metadata.small_bar.cfg` 里
- 传的图片压缩后只存在这台手机的浏览器里（IndexedDB，`src/imgstore.mjs`），设置里只记「idb:编号」；不传服务器（她 11/9 说的）。换手机或清浏览器数据要重新传
- 纯逻辑在 `src/core.mjs`，测试：`node tests/core.test.mjs`

## TauriTavern

她 11/9 起改用 TauriTavern（SillyTavern 的前端 + Rust 后端）。小吧台只用前端的 getContext、事件和 IndexedDB，按理都能用；钥匙本那条路要走 `/api/backends/chat-completions/generate`，要是 TT 不支持就会报错，改用「跟正文」。
