# Small Bar（小吧台）

## 0.10.7 WebKit 音频会话兼容

播放和续播前，在支持的 WebKit 中请求 `navigator.audioSession.type = "playback"`；暂停或结束时恢复先前类型，不覆盖其他功能已切换的录音会话。不支持该接口时继续沿用原生 Audio。此声明与锁屏媒体控制不同，也不会授予 TT App 原生后台音频能力；iPad 后台能否持续播放仍需实机验证。本次测试验证了会话请求、释放、接口缺失/拒绝和原有连续播放流程，没有在真实 iPad 上验证后台保活。

## 0.10.6 按实际聊天边界适配页面

平板展开页按 `#sheld` 实测边界定位，处理 TT 保存的内联 `!important` 尺寸、逻辑宽高和父容器变换；宿主重写旧尺寸后重新对齐。保留原生页面节点与卡片样式，切回手机或关闭美化恢复原先的内联尺寸与优先级。

## 0.10.5 音乐连续播放与图片显示性能

私人图片仍随扩展设置保存，显示改用缓存 Blob 地址，避免切换聊天时反复将图片 Base64 拼进页面；查找引用不再序列化图片数据。音频元素固定挂在界面之外，接入系统媒体控制，暂停后直接续播现有音源；重复缓冲恢复不再反复保存整份设置。后台停止歌词和进度绘制、停止超时换源，前台歌词更新频率降至每秒十次。浏览器验证涵盖界面重置、暂停续播及可见性回调；真实 iPad / TT 的后台保活仍取决于系统和 WebView，需要实机确认。

## 0.10.4 平板页面与预设点击修复

所有美化页面的原生抽屉在平板上占满左栏以外的区域，清除酒馆原有居中变换、宽高上限及内联尺寸；嵌套的角色页也处理外层抽屉。古风当前预设名称区域可直接点开原生下拉选择，底部操作按钮保留。

## 平板双栏面板

开启「酒馆页面美化」和小吧台后，768px 及以上窗口自动显示左侧常驻卡片栏（280–340px），右侧保留聊天和顶栏操作，不再用遮罩覆盖聊天。左栏独立滚动，宽度不受手机页面宽度设置影响；窄屏恢复原来的抽屉。适配目标为 TT 酒馆 2.4.0 的 `#sheld` 聊天容器，使用现有日夜配色。浏览器模拟已覆盖 768、820、1024、1280px 与 390px 切换；仍需在真实 TT 2.4.0 平板上确认其他主题或扩展的布局覆盖。

## 0.10.1 文笺布局修复

修复真实酒馆的纵向列表样式压缩提示条目、名称不可见的问题：条目明确横向排列并可左右滚动。修复 div 类型预设按钮被容器样式误覆盖，保存、改名等操作恢复到底部；竖排标题的括号随英文数字旋转。补齐原生列方向、嵌套 span 控件及 div 按钮的浏览器回归检查。

## 0.10.0 闲庭手记

实装已确认的竖排笺册美化：九个设置页面、闲庭首页、对坐聊天和小吧台外观统一使用细线、小印与宋体，标题用汇迹正楷。预设、世界书条目横向滑动，保留酒馆原生按钮和编辑器。

小吧台「设置 → 外观」打开「酒馆页面美化」，选择「闲庭手记」；也可切回「原版酒吧」。酒馆「装帧」里的主色、辅助色与小吧台「开场与配色」共用同一份数据，日夜分别设置，旧配色、图片和聊天记录保留。字体随扩展本地加载，首次更新文件较大。详见 [闲庭手记说明](docs/folio-theme.md)。

## 0.8.12 群像卡可以关掉自动更新状态

小手机「设置 → TA」里多了一个开关「回复时不自动更新状态」，只对当前这张卡生效。打开后，正文后面不再让TA写状态段，小手机回消息也不顺带更新动态、日记、此刻；「下一轮正文顺带回」会改成马上回。多角色、群像卡用这个；在小手机里手动点按钮生成照常能用。

## 0.8.11 字体统一与首页酒杯

普通文字统一宋体，［…］和 […] 操作使用加粗黑体，保留原花体标题及装饰。酒杯移到默认首页的 The Lounge 标题上方，靠近标题居中摆放，保持低饱和度与轻微倾斜。

## 它怎么工作（给以后来改的人）

- 每轮在正文提示词最后加一段（`src/prompt.mjs`），让他回完正文另起一行写 `<!--SB … SB-->` 状态段
- 收到回复后（`index.js` 的 `absorb`）把这段从正文里剪掉，存到这一楼的 `extra.small_bar`；网页上看不到，下一轮也不会带进上下文。删楼、换页、重新生成都跟着变
- 她在小吧台里做的事（留言、点赞、小手机聊天）存在这个聊天的 `chat_metadata.small_bar`
- 全局设置（API、外观、小猫位置、提示词）存在酒馆扩展设置 `small_bar` 里
- 头图、名片、时代跟着聊天走，存在这个聊天的 `chat_metadata.small_bar.cfg` 里
- 传的图片压缩后只存在这台手机的浏览器里（IndexedDB，`src/imgstore.mjs`），设置里只记「idb:编号」；不传服务器（她 11/9 说的）。换手机或清浏览器数据要重新传
- 纯逻辑在 `src/core.mjs`，测试：`node tests/core.test.mjs`

## TauriTavern

她 11/9 起改用 TauriTavern（SillyTavern 的前端 + Rust 后端）。小吧台只用前端的 getContext、事件和 IndexedDB，按理都能用；钥匙本那条路要走 `/api/backends/chat-completions/generate`，要是 TT 不支持就会报错，改用「跟正文」。

## 世界书编辑与私人图片

古风与原版吧台共用新的条目展开布局：位置、深度、顺序、触发概率、主要关键词直接显示在上方，正文在其后，其他原生选项收进「高级设置」。保留原控件、事件和值，关闭美化恢复原布局。古风连接配置的「查看」结果在卡片下方显示。

图片内容现在保存在酒馆的个人扩展设置中，本地 IndexedDB 作为缓存。同一张新上传图片按内容去重，上传仍沿用裁剪压缩；旧浏览器中被设置或图片归属记录引用的本地图片会自动补入设置。请先在存有原图片的设备打开扩展并等待设置保存，再导出包含扩展设置的酒馆设置/完整数据。只导出角色卡、聊天记录或界面主题不会带上全局图片。图片不进入代码仓库，但个人设置备份会包含私人图片，请自行保管。图片数据会增加设置文件大小（Base64 约增加三分之一），无法做到完全不占存储与内存；清理图片同时清理缓存和随设置保存的内容。
