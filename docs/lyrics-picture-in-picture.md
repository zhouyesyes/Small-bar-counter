# 画中画歌词（试用）

先开启悬浮歌词，点击胶囊展开，在下方点击「画中画歌词」。需要由用户手动启动；不会自动申请跨应用显示。

- 支持 Document Picture-in-Picture 的浏览器使用独立系统窗口，提供上一首、播放／暂停、下一首。
- 其余环境尝试将歌词画布作为无声视频，使用标准视频画中画或 WebKit 画中画入口。音乐始终由原播放器播放，视频流只包含画面。
- 当前客户端缺少画布视频捕获、画中画接口，或禁止相关能力时，会提示无法开启。iOS、Android 和桌面端的实际能力取决于浏览器及嵌入客户端，不能只按系统名称判断。
- 逐字高亮、曲名、前后句、进度和配色跟随当前播放器；不另行查询音源。歌词画面通过音频事件和活动期间的定时刷新更新。
- 切换到其他软件后，持续显示和更新取决于系统后台策略。关闭酒馆页面或终止应用后无法继续；此功能不能保证绕过客户端的后台限制。
- 关闭画中画会释放视频捕获流与定时刷新，不停止音乐。页面内的歌词胶囊可以独立关闭。

验证：`node tests/lyrics-pip-runtime.cjs` 使用本地音频，覆盖 Document／标准视频／WebKit 适配、关闭重开、画面更新、静音视频流、释放资源及不支持／被阻止的回退。适配器模拟不代表 iOS 真机验证。额外调用实际 Chromium 原生画中画接口；无桌面环境可能拒绝，脚本会单独报告结果，不将模拟成功当作原生成功。
