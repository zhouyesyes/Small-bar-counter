# 闲庭手记：审阅修正

本批修改经逐项审阅，并按用户要求连同调色保页、TT 面板恢复和图片归属修复合并到 main；本轮版本标记为 0.10.2。配色仍以小吧台已有的 `splash.colors` 为准，图片与原生编辑数据保留。

## 已整理的页面

- 文笺：辅助小按钮移到“当前预设”下方竖排；操作按钮与条目维持原生事件。兼容 TT 按 API 动态插入的 `ttas_agent_embed_preset_*` SVG 入口，按原 API 区块显隐；保留原节点与点击事件，关闭美化时还原位置。识别依据为 [TauriTavern 原生按钮实现](https://github.com/Darkatse/TauriTavern/blob/main/src/scripts/extensions/agent-system/src/embedded-assets-buttons.ts)。
- 传讯：完整原生连接面板默认展开，包含 API 类型、来源、模型、后处理、附加参数与密钥管理；卡片底部操作统一字号和间距。
- 章法：所有分组统一为窄长竖条、上方横滑；多个原生编辑器可以同时展开，并按页面原顺序排列。保留完整设置，减淡边框；元数据开关保留为淡色闪电。
- 世间录：原条目留在原列表中，目录在上方横滑，展开编辑器在下方按原顺序显示；条目名称与参数恢复横排。底部保留蓝、绿、灰三个圆点，仅将文字换成“长明笺／应声笺／封存笺”；不改原生状态选项。“新增条目”显示为“添一笺”。
- 装帧：小吧台及美化标题字体随样式切换；小调色盘在页面下方实时预览背景，取消恢复原色，确认才通过原保存流程写入。拦截调色操作的外部点击，保留当前设置页和滚动位置。所有分组使用闭合细框。
- 借景：标题、工具栏和图片在同一滚动区域内；保留原菜单与回到顶部操作。
- 百工匣：修复两个入口的白色焦点框与点击区域溢出，键盘焦点使用主题色提示；下方分组补齐四边，原生 details 包裹时避免双层框。
- 名帖：保留原来的左右布局与紧凑尺寸，合为同底色、同外框的一张帖子；左侧上方长方形头像占约三分之一，下方姓名与操作紧凑竖排；右侧仍是“名帖所系”及三个等距竖栏，两侧没有间隙，只以一条竖线分隔；关联世界书显示为“系一卷”；其他设置从标题下方展开。三个范围显示“常用此帖／系于此人／用于此叙”，分别对应原生默认人设、当前角色、当前聊天的锁定按钮。其他页面保留原有页边距。名帖采用较深的同色底。

- 故人录与其他名帖：列表用 88px 宽的窄长名帖卡，长方形头像在上，下方姓名、备注、版本、标签与常用/绑定标记竖排，所有条目无间隙紧贴，在同一行左右滑动。网格模式保留每行三个方格、圆头像，放大头像并放松间距，只保留姓名和常用/绑定标记，备注、标签与版本保留在列表模式；长姓名单行超出省略；去掉置顶区残留的双短横线；“新建名帖”显示为“落一名”。搜索改为“寻一位故人”，排序文案随主题切换；原生筛选入口改成“常念／同行／书匣／理签／寻签／清筛”小印签，保留选中与排除状态。“新建角色”显示为“逢一人”；其人页“关联世界书”显示为“世间录”。首页快捷入口与顶栏共用这一套线条图标；聊天输入框统一行高与上下留白，保留多行展开与原生进度条。

## 故人录筛选与图片

置顶区与角色卡收藏标记统一显示“常念”。筛选按钮取消换行，覆盖 TT 原生圆按钮的最小尺寸；“清筛”紧接其余入口，极窄屏可横滑。人设默认项仍保留“常用”语义。头像继续使用宿主的缩略图与原生图片节点，没有重新压缩或改写图像分辨率；延迟加载、异步解码和固定布局可能减少渲染等待，但不据此推断具体设备上的性能提升比例。

## 竖排与按钮底线

传讯、连接配置、预设及世界书的竖排操作文字统一贴近卡片内框下线，短标签从底部向上留出空间。全部主题竖排区域统一英文与数字的正向逐字字形；各类括号使用横排字形，避免字体自动替换成竖式括号。原生输入框、下拉选项与可编辑内容不拆分，关闭美化时还原包装。[传讯底线与字形预览](folio-runtime/api-bottom-aligned.png)使用测试数据演示。

## 配色、切换与 TT 面板恢复

小调色盘放在所属抽屉/设置对话框内，支持时使用浏览器顶层显示；TT 在捕获阶段检查外部点击也不会把装帧页关掉。预览撤销不再重入切换清理。监听宿主配色与同步完成时使用最新设置对象；旧配色入口也重新绑定到同步后的数据，避免写回旧对象。

切换时还原原生节点不再要求它们连接在文档上；TT 暂存到离屏片段中的节点、标记和自建外框也能清理。预设未加载时不提前标记挂载完成，章法支持整页及部分分组延迟加载；反复切换后不重复建卡、不丢落笔有度和原生编辑值。

## 验证

浏览器回归入口为 `tests/folio-runtime.cjs` 与 `tests/profile-cover-runtime.cjs`，新增 TT 捕获阶段外部点击、同步对象替换后的保存、离屏面板还原、整页/部分延迟加载及真实随身导航下的图片隔离检查。除原有事件、节点身份、颜色双向同步、编辑值保留与关闭美化恢复外，补充多条展开顺序、手机宽度、不跳页调色、取消不保存、彩色状态点、方形头像和绑定按钮等检查。

另以酒馆上游完整原生 DOM 进行了本地结构核对：传讯 140 个原生输入控件、章法九个分组，以及完整世界书头部与编辑模板的控件保留。静态结构检查不能代替用户设备上 TauriTavern 与全部插件组合的实际运行。
