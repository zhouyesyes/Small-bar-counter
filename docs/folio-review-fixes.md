## 已整理的页面

- 文笺：辅助小按钮移到“当前预设”下方竖排；操作按钮与条目维持原生事件。
- 传讯：完整原生连接面板默认展开，包含 API 类型、来源、模型、后处理、附加参数与密钥管理；卡片底部操作统一字号和间距。
- 章法：所有分组统一为窄长竖条、上方横滑；多个原生编辑器可以同时展开，并按页面原顺序排列。保留完整设置，减淡边框；元数据开关保留为淡色闪电。
- 世间录：原条目留在原列表中，目录在上方横滑，展开编辑器在下方按原顺序显示；条目名称与参数恢复横排。底部保留蓝、绿、灰三个圆点，仅将文字换成“长明笺／应声笺／封存笺”；不改原生状态选项。“新增条目”显示为“添一笺”。
- 装帧：小吧台及美化标题字体随样式切换；小调色盘在页面下方实时预览背景，取消恢复原色，确认才通过原保存流程写入。拦截调色操作的外部点击，保留当前设置页和滚动位置。所有分组使用闭合细框。
- 借景：标题、工具栏和图片在同一滚动区域内；保留原菜单与回到顶部操作。
- 百工匣：修复两个入口的白色焦点框与点击区域溢出，键盘焦点使用主题色提示；下方分组补齐四边，原生 details 包裹时避免双层框。
- 名帖：统一为无外侧留白的一张通栏帖子，上方长方形头像封面占整帖约三分之一，下方姓名与操作紧凑竖排；“名帖所系”接在同一帖子下方，底色完全相同，只以一条横线分隔；关联世界书显示为“系一卷”；其他设置从标题下方展开。三个范围显示“常用此帖／系于此人／用于此叙”，分别对应原生默认人设、当前角色、当前聊天的锁定按钮。各设置页移除外侧横向留白。
