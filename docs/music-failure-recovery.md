# 音乐失败跳歌与 QQ 歌词排查

当前播放器先检测同一首歌的多个来源。全部失败后自动跳过该曲；单曲循环遇到失败也会尝试其他歌曲，随机模式只从本轮尚未失败的歌曲中选择。整张歌单都失败时停止并提示，用户手动播放可开启新一轮重试。暂停、停止或切换歌曲会取消待执行的跳歌。聊天选曲生成的动态列表每次可能返回不同的数组，因此用当前歌单与目标曲目对象确认跳转，不依赖数组引用相等。

QQ 歌词直接调用 `/v2/music/tencent/lyric`，优先使用 MID，不再依赖播放地址接口是否返回歌词；同时解析 QQ 的 `文字(起点,时长)` 与网易云的 `(起点,时长,标记)文字` 两种逐字格式。并发歌词请求合并，失败结果不永久缓存；播放资料迟到时附带的歌词可以刷新当前展示。

播放地址保留高音质与标准音质请求，增加接口自动选择可用未加密格式的兜底。接口返回“试听”时保留试听标记，不将其标成完整会员音源。
