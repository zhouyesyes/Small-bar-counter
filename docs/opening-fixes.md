# 开场修复

- 展开只切换中间单据，底部条形码、进入和略过按钮始终可见。
- 去掉卡片与外框高度渐变，切换时只计算一次尺寸，中间单据用 140ms 的透明度与位移动画。浏览器检查一次展开的 LayoutCount 增量为 3，不再持续逐帧布局；真实 iPhone 效果仍需用户试用。
- 我的名字、头像、签名存在当前聊天 small_bar.cfg.me；未设置时跟随当前酒馆人设。旧全局资料保留，但不再自动用于全部聊天，可在我的资料页手动沿用到当前聊天。
- 开场头像跟随当前聊天的我的资料，除非在开场面板明确设置了固定头像。聊天和人设切换时刷新，图片加载完成也会同步。
- 未就绪时酒杯停在实际进度；进入时若已经就绪，播放约半秒的空杯到满杯过渡再退出。

验证：人设隔离测试、浏览器聊天头像 A→B→A 切换、折叠直接进入、保存、裁剪与 IndexedDB、宿主延迟完成事件、展开布局与既有开场交互通过。未修改主题自带的进入页。
