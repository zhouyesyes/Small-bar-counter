# 闲庭手记（0.10.0）

在小吧台「设置 → 外观」开启「酒馆页面美化」，样式选择「闲庭手记」。已有的美化开关状态保留；更新不会自动打开此前关闭的酒馆美化。可随时选择「原版酒吧」或关闭美化。

顶栏依次对应：文笺（预设）、传讯（连接）、章法（格式）、世间录（世界书）、装帧（设置）、借景（背景）、百工匣（扩展）、名帖（人设）、故人录（角色）。首页为闲庭，聊天为对坐。采用确认后的干净线条方案，不加入红叶、根系或新生成图片。

## 共用配色

装帧里的「小吧台 · 共用美化」与小吧台「开场与配色」读取、修改同一组 `settings.splash.colors.light/dark.bg/accent`。日夜各有主色、辅助色；已有值优先，仅缺失的颜色填入新默认值。图片、个人资料和聊天配置保留。

新入口通过 `host.appearance.get(mode)` / `host.appearance.set(mode, { bg, accent })` 接入旧保存流程，同时刷新扩展设置、开场缓存和已打开的配色窗口。新增入口应复用这个接口，不另设配色键或 localStorage。

## 原生功能与恢复

调整的是原生控件的位置和外观，预设选择、世界书、格式编辑器、背景菜单等仍使用原节点和事件。格式卡片打开后，原编辑器显示在下方宽区域；收起或切换时还原。切回原版、关闭美化时，恢复节点、标题和属性。

字体来自用户指定参考：正文京華老宋体，标题汇迹正楷，均本地加载；来源及许可见 [字体说明](../assets/folio/fonts/NOTICE.md)。正文原文件约 31 MB，首次更新和加载可能稍慢。

## 验证

Node 检查涵盖共享配色的原子更新、旧数据保留、默认值填充，以及既有配色、聊天、个人资料模块。浏览器检查使用 `tests/fixtures/folio-runtime.html` 的原生结构夹具，覆盖十个设置/详情页面、聊天、原按钮事件、编辑器值保留、配色双向同步与开场缓存、切换样式及关闭后的恢复。

运行浏览器检查：在仓库根目录启动 `python -m http.server 8870`，安装 Playwright 后执行 `node tests/folio-runtime.cjs`。可用 `FOLIO_BASE_URL`、`PLAYWRIGHT_MODULE` 和 `CHROMIUM_PATH` 指定测试地址、依赖与浏览器。检查尚未覆盖用户设备中的 TauriTavern 和所有第三方扩展组合。
