# 未进入聊天的主页

没有选择角色聊天时，小猫入口和扩展面板的打开按钮都能使用。页面仅含个人头图、头像、小字和完整音乐播放器，不显示动态、此刻、日记或手机社交应用。

个人主页使用独立的 settings.home 资料，不读取或写入聊天人设、角色资料或开场卡片设置。默认头像和背景使用 assets/opening 中的图片。头像和“换背景”可直接上传裁剪，“编辑我的主页”内也可以换图、修改名字与签名。进入聊天后才显示聊天的角色页面。

聊天切换只重置显示的视图，保留抽屉/浮窗的打开状态，也保留 createPlayer 实例、Audio 对象、歌单、曲目与进度，不暂停、不重播。

验证：模拟宿主的真实入口浏览器检查覆盖主页打开、无动态标签、直接上传与裁剪、面板入口，以及主页→角色聊天→主页。使用本地 WAV 音频检查同一个 Audio 始终未暂停且 currentTime 持续增长；没有请求第三方音乐接口。并复查此前的头像隔离、折叠直接进入、开场保存和宿主完成事件。
