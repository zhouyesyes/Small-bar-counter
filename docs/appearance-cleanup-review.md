# 装帧与随身匣入口整理

本批以 0.10.2 为基础，原生 UI 主题联动仅讨论，不修改其字体滑杆、头像形状、聊天风格或颜色存储。

- 竖排中文保留；英文、数字和括号连续侧转，覆盖主题所有竖排区域及动态加入的条目，不再逐字直立。
- 装帧保留日间、夜间并排的细框卡片；卡片内主色、辅助色各一行，色号取消深色代码背景，紧跟 13px 圆形色点。外观对话框缩窄，页面宽度改称“小吧台宽度”，其中日夜配色各占一行，四个图片上传项显示当前缩图。
- 默认随身匣移除头图铅笔，保留直接换头像/头图；署名、签名、座位、酒单和日期可原位修改，沿用全局个人资料。默认页齿轮仅移除头像/背景/配色入口。
- 恢复原生助手问候，保留原消息内容；头像和头图共享默认随身匣的日夜图片。未设置时使用原生助手头像和灰阶头图。
- 聊天头像、头图可点击裁图上传。角色头像/头图写回角色资料；自己的头像/头图写回个人资料及朋友圈头图；X 的独立来源保持原有归属。裁图中切换聊天会放弃写入原聊天以外的资料。
- 随身设置移除重复的开场/配色、美化开关与样式入口；时代移到外观并命名“美化时代”。“浅／深／跟美化”只影响随身匣。启用开关显示辅助色；小手机上方横条改为纯底色。

## 原生 UI 设置的讨论建议

| 控件 | 当前用途 | 建议 |
| --- | --- | --- |
| 字体大小 | 原生界面的缩放；自定义固定字号暂不响应 | 后续让已有滑杆同时控制自定义字号，不另建一套 |
| 头像样式 | 圆形、方形等头像形状 | 待确认聊天卡片是否跟随，暂不改 |
| 聊天风格 | 原生消息的平铺、气泡、文档布局 | 与当前自定义消息布局一起设计，暂不改 |
| 媒体样式 | 附件列表或图库 | 保持独立 |
| 通知 | 提示出现的位置 | 保持独立 |
| 主题颜色 | 正文、斜体、引用、阴影、聊天/UI 底色、边框、双方气泡等 | 后续从装帧主色/辅助色推导，优先保留单一配色入口；确认前不覆盖原生主题 |
