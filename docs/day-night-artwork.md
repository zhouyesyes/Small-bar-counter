# 日夜默认配色与图片

默认界面改为中性黑白灰：日间浅灰背景、深灰按钮；夜间深灰背景、浅灰按钮。保留用户已保存的自定义配色。

用户最终确认：飞机头像与云天空横图用于日间，月亮头像与夜空横图用于夜间，文件原样保存到 assets/opening，未重新生成或改变颜色。

开场与个人主页分别保存 images.light / images.dark，每套包含 avatar / cover。直接点击主页背景或头像修改当前模式，主页编辑面板可分别修改日间和夜间图片；开场外观面板同样有两套上传与恢复默认入口。旧版单张自定义图片继续作为兼容后备，不绑定角色或聊天人设。

检查：黑白灰色值、两套默认图片切换、四个开场上传入口，以及按模式自定义头像隔离。真实设备显示效果待体验。
