# 小手机：界面与剧情时间线

现代默认美化使用带圆角机框和顶部听筒的 iOS 风格界面，古风、民国与文笺继续使用原有页面。所有软件仍走现有业务入口，未引入另一个聊天存储或播放器。图标使用小尺寸本地 App artwork，出处在 `assets/phone/sources.json`；控制图形使用 Ionicons，许可证随资产保存。

## 锁屏与页面

- 每次进入聊天重置锁屏；同次聊天关闭、重新打开、调整外观不重复锁屏。不涉及真实设备密码或生物识别。
- 日期和时间来自剧情与状态，不拿系统日期冒充故事日期。内页移除原来的大时钟，保留细状态栏。
- 可点按 / 上滑解锁；软件无图标下方标签，按钮保留名称供辅助阅读使用。进入软件有轻微缩放，跟随系统减少动态效果偏好。
- 锁屏音乐、音乐软件和吧台共用一个 Audio：播放、暂停、上下首、进度及音量控制接现有播放器，不重新加载音源。
- 手记列表与详情留在手机内，喜欢、纸条、复制、删除维持原入口。屏幕照明按钮只照亮模拟手机页面。
- 保留 Claude 新增的线上人设、提示词分块、微信删除模式与系统黑体。手机始终嵌入抽屉，旧浮窗设置不会再弹出单独窗口。

## 壁纸与微信

设置 → 资料与样子 → 手机壁纸，为锁屏与桌面分别选择图片；上传沿用裁剪工具，可拖动、缩放及取消。图片通过现有 `saveImage` 保存，引用放在当前聊天 `cfg.phoneWallpapers.lock / home`，原图内容随扩展设置的 `imageData` 导出。两张图独立恢复默认，不关联吧台头图；切换聊天不继承上一聊天的配置。跨聊天完成的旧裁剪不会覆盖新聊天壁纸。

微信新增真实会话列表和本地搜索，不虚构可点击但无法对话的联系人会话。底部四个入口复用原有的微信对话、通讯录、朋友圈和个人资料。聊天气泡、输入栏、绿色发送按钮与明暗背景限定在现代默认手机，保留原消息 ID、发送队列、长按编辑、删除模式及线上人设流程。

## 手机活动如何进入剧情

`MESSAGE_SENT` 只处理正常用户剧情消息，将尚未带入剧情的手机活动保存到该楼层的 `extra.small_bar_phone_timeline`。每个聊天的 `chatMetadata.small_bar.phoneTimeline` 记录已处理的来源 ID。第一轮升级时以当前手机数据建立基线，从此后的新活动开始；不开启批量回填旧记录。

manifest 的 `generate_interceptor: smallBarPhoneTimeline` 处理宿主准备的历史消息副本，只在携带上述附属数据的那条消息前加手机记录。已核对 SillyTavern 与 TauriTavern 上游的接口、`MESSAGE_SENT` 时机及保留 `extra` 的历史复制流程。宿主会过滤系统消息并重排 `index`，因此使用消息自带的 `extra`，不拿这个索引回查原聊天，避免位置串楼。

这使手机事件出现在下一条剧情的原有位置；重试与继续生成重用同一份记录，之后的剧情楼层不会重复取得旧事件。旧楼层不在上下文内时，手机记录也不在；导出聊天及其元数据时保留锚点与已处理状态。纯手机 API 请求没有发出新剧情消息，不会提前消耗待带入的活动。关闭开关时下一次剧情跳过待带入活动，不删除手机自身记录。

收集微信已发送消息、X 各账号私信与用户动态、用户朋友圈及评论，以及手机独立生成的朋友圈、X、微博和互动。未发送草稿不带入；剧情回复本身生成的状态不额外当成一次新手机活动。已锚定的记录是当时快照，之后编辑或删除手机气泡不会悄悄重写已发生的剧情。

线上记录逐项标明用户手机视角、渠道、顺序、已有剧情时间与可见线索；不把真实设备操作时间当作故事时间。微信拒收标记对方未收到，X 小号不自动与线下身份关联。朋友圈、微博、X 与其他动态均是用户的信息流，不是对方手机或窥探功能。一般不代表角色知情；共友、双方确实刷到同一条、实际互动、转发或告知时依据剧情判断。好友与知情状态可变化，不要求用户维护名单，也不将一次猜测写死。朋友圈须根据人设、世界书、关系及权限判断是否可见；未知关系保留未知，公开帖子不代表角色已经阅读。规则要求模型区分叙事资料与角色知情范围，不把记录文字当系统指令。

「下一轮正文顺带回」仍保留；生成末尾只提醒存在待回复消息，不再复制其内容。实际消息只从它所在的历史时间点读取。

## 参考与验证

用户提供的 BLMX 预设 / 快捷回复展示了独立日志和线上消息格式；芋圆机附件只是远程脚本入口。只读检查了其公开脚本的注入逻辑，未导入或执行附件。另一份 MiPhone 附件也是远程页面入口，该链接未取得有效页面，不能据此确认完整实现。本扩展不读取其他插件的私有消息存储，也不修改用户现有预设或世界书。

自动验证：

- `node --test tests/*.test.mjs`
- `node tests/phone-timeline-runtime.cjs`：真实 main 入口，宿主边界模拟；跨应用顺序、一次锚定、不污染正文、无末尾重播、历史过滤与裁剪、关闭自动状态和安静生成。
- `node tests/phone-ios-runtime.cjs`：真实 UI 与本地音频；锁屏、无文字图标、音频连续、手记操作、聊天切换、旧浮窗设置兼容与手机尺寸。
- `node tests/phone-wallpaper-wechat-runtime.cjs`：独立壁纸上传 / 裁剪 / 取消 / 重置、可导出图片、切换聊天与过期裁剪隔离；微信列表、搜索、四个入口、长消息、发送、删除、请求中的视角规则、手机与平板明暗布局。
- 线上人设、提示词编辑器、抽屉、音乐连续、玻璃、日历字体和平板布局既有浏览器检查。

浏览器检查不能替代用户设备上 TT 与全部插件组合的实机运行。
