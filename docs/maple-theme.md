# 红叶 · 拾叶集（0.9.0）

更新扩展并刷新酒馆，在「扩展 → 小吧台」打开「吧台美化」，再选「美化风格 → 红叶 · 拾叶集」。默认的小吧台风格保留，可随时切回；关掉吧台美化会移除两套主题的页面装饰。

底色与辅助色继续在「开场与配色」调整，日夜各一套。上下栏实际底色、按钮和线条跟随辅助色；枝叶月纹是独立遮罩，不把底色锁成红色。图标与输入文字根据辅助色自动选择黑或白。没有自选颜色时，红叶主题使用暖纸朱红／夜林浅铜作为初始配色；已有颜色不会被覆盖。

首页用新绘制的平涂旧印刷红叶背景，落叶向下过渡。九个功能页与聊天标题统一复用首页同一张红叶画作的上部，接文楷标题和轻磨砂卡面；不再使用另外绘制的页顶叶子。页眉在普通文档流里，向下滚动后随内容离开视野，不悬浮或固定：枝序（预设）、汲泉（API）、文理（格式）、万象志（世界书）、时色（界面）、林间（背景）、随行匣（扩展）、拾叶人（人设）、众生枝（角色）。实际预设、世界书、API、人设绑定等仍使用原生控件与数据，不把设计样稿里的假值写进酒馆。

聊天页只把标题改为「叶间续章」，补同风格页顶装饰；保留现有阅读布局、头像头图来源以及原生正文、编辑、重生成和切换回复功能。主题不改提示词、状态块或聊天记录。卡片内部的状态栏、日记和小手机不在本轮改造范围。

首页背景插画保留原画色，不承诺粉色纸面能被任意颜色完全替换；底色选项控制 UI 层。字体与绘画是本地静态资源；霞鹜文楷完整字体约 13 MB，第一次选用会加载并缓存，加载期间有宋体回退。

## 素材和许可

assets/maple/home.webp、pattern.webp 来自本次设计过程中生成的原创插画，已转换为 WebP，两张合计约 0.9 MB。没有裁取参考图的人物或水印。

assets/maple/wenkai.woff 来自 [霞鹜文楷官方仓库](https://github.com/lxgw/LxgwWenKai)，由原始 TTF 转成 WOFF。保留完整 OFL 许可在 assets/maple/OFL.txt。不依赖外部字体 CDN。

## 验证及边界

主题、聊天、颜色、个人资料、音乐等七个测试文件通过。另有 tests/core.test.mjs 的旧解析断言失败，已用修改前 HEAD 的 core.mjs 和测试文件在隔离目录复现；本次没有修改该解析器。

Chromium 通过 tests/fixtures/maple-theme.html 加载真实美化模块，检查了：两套主题相互切换；聊天正文与编辑按钮节点、原始处理函数保持；世界书选择器身份与选值保持；关闭主题后清理主题节点；首页标题；深色和浅色辅助色上下栏同步；手机宽度无横向溢出。页面无 JS 异常或美化模块警告。另验证首页与世界书下滑 500px 后，标题红叶区域离开视野；功能页复用 home.webp，页眉无 fixed/sticky，首页背景为 local 且不重复。
