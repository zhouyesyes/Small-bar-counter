# 原版吧台与聊天表面（0.12.0）

## 设置与数据

`settings.glass` 保存 enabled、transparency、blur、width。缺省启用，透明度 35%、模糊 16px、宽度 94%；按字段验证并限幅，零值有效。它与个人图片、开场署名、抽屉手机/平板宽度互相独立，随酒馆扩展设置保存。

酒馆 UI 共用美化、开场与配色、小手机外观都调用同一组控件。input 只更新表面和数字，不触发整页 render 或保存；change 才调用原来的设置保存回调。所有打开的控件同步显示。宽度以聊天区为基准，100% 清除侧面留白和外缘圆角，不会把左侧抽屉也覆盖。

只在吧台美化开启且 barStyle 为 default 时挂 sb-glass-chat。关掉效果、关美化或切闲庭手记，类和变量移除，原宿主布局恢复。真实背景继续由酒馆管理，不复制到仓库、不重新上传、不把用户图当扩展内置图。没有 backdrop-filter 的浏览器使用实色阅读底作为后备。

## 原生聊天与性能

继续使用 src/bar-chat.mjs 的 After Hours、逐条头图、头像姓名与原 `.mes_text`。The Lounge 仍属于首页。本次只加 #chat 与 #send_form 的外层表面，没有把正文复制进另一套阅读器，没有替换编辑、切换回复与流式更新的节点。

唱片卡显示当前歌曲封面；唱臂、旋转状态读取实际播放器状态，不增加音频元素、不重载音源。页面隐藏时停止装饰动画和原有进度绘制；减少动态效果开启时不旋转唱片。私人图片与音频存储机制不变。

## 日历和历史

日历是酒杯状态 section 的同级，独立展开状态、剧情月份和事件源保持原实现。历史入口在音乐后，状态栏内没有重复入口。

buildState 只为有效酒杯回复保留小型摘要；snapshot 为不可枚举的延迟 getter，点击详情时按当时的回复前缀重建完整状态，不取今天的数据重画历史。重建关闭历史索引生成。现有选中 swipe 与手动重做版本筛选沿用 main.mjs；切换聊天会关闭详情并重置历史分页。初次十张、向下滚动或按钮每次再十张；程序滚动恢复、自动定位到按钮不会误触发再加载。早前文字记录继续可查看。

## 检查

- Node 测试：设置边界与零值、私人字段保持、历史快照与后续差量隔离、其余状态/配色/图片/提示词等单元检查。
- glass-history-runtime：独立日历、历史批次及选中状态、滑条实时/松手保存/重开、多入口同步、100% 两侧贴齐、宿主节点保留、主题/竖屏/手机。
- cocktail-panel-runtime、cocktail-host-runtime：真实组件与主入口、日历事件/杯型/弹窗、规划请求和跨聊天隔离。
- music-continuity-runtime、audio-session-runtime：音频不随 UI 重建、暂停续播和 WebKit 会话。
- native-theme-runtime、drawer-controls-runtime、tablet-drawers-runtime、helper-dialogs-runtime、profile-cover-runtime：原生主题控件和明暗隔离、抽屉限宽与原生页面/助手管理器边界、图片归属。
