# 定下来的样子和做法

写给之后来接着做的人（可能是另一个窗口的 cc，也可能是过几天的自己）。她说过的话放在最前面，改之前先看这里。

## 她要的（2026-11-09）

- **一个扩展**：不要世界书。提示词都写在扩展里，她能在扩展里直接改
- **手机优先**：她用 iPhone 的 Safari 开酒馆（主题是 QuietRoom，左上角已经有一颗粉色爱心钮，别撞）
- **不要右滑手势**：网页会退出去。所有东西只能点
- **不要太杂**：参考的那个（Rainday）功能太多、设置一大堆。先做少、做精，以后一样一样加
- **风格**：黑白、极简、ins 一点。浅色是白底黑字，深色是黑底白字
- **先出样子图，她点头了再写代码**

## 功能框架（11/9 她给了 Rainday 的说明当参考：参考每块功能的框架，不照抄；她不要的不做）

还在商量，下面是 cc 整理的草稿，**她没点头的都不算定了**。

1. **小手机聊天**：连发几条、点 ↑ 才回，不新增正文楼层；他的回复一条条出来；长按编辑 / 删除；「＋ → 重生成」收回他这一轮、失败恢复。＋里：表情包（本地传或「名字: 图片链接」批量导入，两人共用）、语音条（点开看文字）、虚拟图片（点开看描述，不生图）、转账（可收可退）。联系人：互相拉黑、好友申请，关系变了他改你的备注，聊天里留一行居中小字。时间接着剧情走，正文更新后再进来提示校准，也能手改
2. **账号和记忆**：分账号（工作 / 私人……）；「他认出你」「你认出他」两项分开设（没认出 / 怀疑 / 确认），可勾他线上已知道的资料；每个联系人记最近 N 条（默认 50），可选带进正文、可选给别的账号参考
3. **X**（公开的网上身份，可单独关）：他的主页（头像、背景、网名、账号、简介都能改）；随剧情 0～2 条新帖，显示最新 15 条；点赞、收藏、留言、搜索、删帖；私信是另一段关系（你对他是陌生人），他可能已读不回、拉黑；你可以有多个 X 账号；从 X 加到小手机
4. **动态**（她说和 X 是两个东西，cc 理解成朋友圈：熟人圈子、现实身份，待她确认）
5. **此刻**：时间、天气、在哪、穿着、想要（心跳）、心声（翻面看另一面）；备忘录（要做的事，最多 15 项）
6. **日记**：不强制每轮写，酌情 0～2 篇，列表显示最新 3 篇；笔名署名；喜欢、留小纸条、存成图片、复制、删除
7. **音乐**：要第三方的歌源，待她决定要不要
8. **不做**：灵动岛；拖动缩放窗口；雨 / 雪 / 尘这类特效
9. **和 Rainday 不一样的地方**：一个扩展装好就能用，不要酒馆助手、不要正则、不要世界书；API 跟正文或从钥匙本挑；「省一点」开关（小手机回复时不顺带写心声、日记、新帖）
10. **以后**：不同时代换一套样子（现代 / 民国 / 古风），扩展读角色卡猜时代，她可以改

## 入口：横着探头的像素小猫

- 黑白像素猫头，**整个头横过来**（转 90 度，耳朵朝右），从屏幕**左边缘**探出来，像躲在墙后歪头往外看；左边一小截藏在屏幕外
- **不要爪子**（她说的）
- 浅色主题是黑猫，深色是白猫
- 平时偶尔眨眼；有新消息时耳朵旁边冒一颗小心
- 只能**点**：点了滑出抽屉
- 样子：[mockups/cat.png](mockups/cat.png)（灰线是屏幕左边缘），画法：[mockups/cat.py](mockups/cat.py)
- 还没定：大小、放在左边多高、要不要能上下拖着挪

## 抽屉：从左边滑出来

> **11/9 她改的（在商量，还没定）**
> - 抽屉顶上像 X 个人主页 / 朋友圈：背景图，头像压在背景下沿居中，名字、账号、签名、剧情时间天气
> - 四个标签放在抽屉最底下（她说的）：**动态**（只放最新三条，底下「更早的在小手机的 X 里」）/ **此刻** / **日记** / **小手机**（点了弹小手机）
> - **日记**：他写的，一天一篇，最上面是今天的，下面列以前的日期和标题，点开才加载那一篇
> - **小手机里加一个 X**：顶上切「聊天 / X」，X 页照她给的参考（背景、左边头像、私信 / 关注、关注数、帖子 / 回复 / 转发 / 媒体、底下一排图标）；全部动态在这里翻，往下滑才一段一段加载，不打开就不加载，免得卡
> - 背景每个角色分开设，三种（她 11/9 定的）：**跟天气**（不传图，按状态数据里的天气和时间换**黑白灰**的背景：晴、阴、雨、雪、夜；**不要像素**，她说不好看）/ **固定一张**（传一张不变）/ **他来挑**（传多张各写标签，提示词里列出标签，他在状态数据里写一个，扩展换上；写了不存在的就留着上一张）。入口是背景左下角「背景」小钮，样子 bg-*.png（`?s=profile&bg=1`）
> - 她传了图就原样用，**不在图上加雨丝雪花**（她 11/9 说的，rain-*.png 是看过后不要的样子）；黑白灰天气背景只在「跟天气」（默认）时出现
> - 天气这些数据都是正文模型在同一次回复里顺带写的，不另外请求 API；扩展在手机上读出来、藏掉，不带进下一轮
> - 内容都跟着聊天变：每个聊天各存各的，删楼 / 重新生成就撤掉那一楼带来的动态和日记
> - 样子：profile-*.png、now-light.png、diary-*.png、x-*.png（`mock.html?s=profile&tab=posts|now|diary`、`?s=x`）
>
> 下面是原来那版：

- 宽约 318px（手机上右边还露一截正文，变暗），顶上写 `SMALL BAR` 和关闭 ×
- 三张卡，细边框圆角卡片，小标题是小号大写字母加中文（`NOW · 此刻`）：
  1. **此刻**：头像、名字、账号；一行日期 / 时间 / 天气；「在哪 / 穿着 / 想要」（想要前面一颗小心）；「心声」右边一个「翻面」（翻过来看藏着没说的那一面）；最底下一句签名（斜体、居中、灰）
  2. **动态**：角色最近发的帖子，像 X / ins：头像、名字、几小时前、正文、照片（只写画面描述的灰块）、点赞评论转发数
  3. **小手机**：头像、「小手机」、最后一句消息、未读数；点它弹出小手机
- 样子：[mockups/drawer-light.png](mockups/drawer-light.png)、[mockups/drawer-dark.png](mockups/drawer-dark.png)

## 小手机：弹出来的小窗

- 约 300×540，圆角 30，浮在正文上（底下变暗），不铺满屏幕
- 顶上：头像、名字、「在线」、关闭 ×
- 气泡：你的在右边，黑底白字（深色里反过来）；他的在左边，细边框
- 消息种类：文字、语音条（声波 + 秒数，点开看转写）、照片（灰块里写画面描述，不是生图）、表情包、转账（纯剧情）
- **连发几条再点 ↑ 他才回**：没发出去的下面写「待发送 · 点 ↑ 他才回」；他在回时显示「· · ·」，一条一条出来
- 底下：＋（表情 / 语音 / 照片 / 转账 / 重新生成）、输入框、发送箭头
- 样子：[mockups/phone-light.png](mockups/phone-light.png)、[mockups/phone-dark.png](mockups/phone-dark.png)

## 打算怎么做（还没写，供参考）

- **API**：小手机默认跟正文用同一个；也能从「酒馆你害我不浅」的钥匙本里单独挑一条（她选的）
- **提示词**：不靠世界书，用酒馆给扩展注入提示词的接口，开关和内容都在扩展设置里
- **状态数据**（此刻那张卡的内容）：每轮跟正文一起出一小段数据，扩展读出来更新卡片，正文里不显示、也不带进后面的上下文（不靠正则）
- **时间跟着正文走**：聊天时间接着剧情里的日期，不跟现实时间
- 她的酒馆是 **SillyTavern 1.18**：写之前先对着 1.18 的源码核对接口，旧版本少导出的名字要有退路（「酒馆你害我不浅」0.6.0 就因为这个整个加载不出来）
