# 原生 UI 控件接入装帧

本批接续 PR #38；此前仅讨论的原生控件联动现按用户确认实施，暂不迁移其余 UI 选项。

| 原生入口 | 装帧中的名称 | 接入方式 |
| --- | --- | --- |
| UI 背景 `blur-tint-color-picker` | 主色调 | 移动原控件所在行，沿用原生 `change` 保存事件 |
| 引用文本 `quote-color-picker` | 辅助色 | 移动原控件所在行，沿用原生 `change` 保存事件 |
| 字体比例 `font_scale` 与计数器 | 字号 | 移动完整原生滑杆行，沿用输入事件及 `--fontScale` |

原生节点及 ID 保持不变，原位置不留下副本。使用紧凑调色盘编辑，确认通过原组件的颜色 setter 触发宿主事件；保留原保存流程。主色选 UI 背景，辅助色选引用文本，与已有底色及点缀色语义对应。其他主题颜色、头像样式、聊天风格、媒体和通知控件保留原位。

日间、夜间仍是并排的细框卡片。同一组原生颜色控件位于当前明暗卡片，另一套配色用原有预览入口编辑，确认后写回该套配色；原生当前主题最终保持当前明暗的颜色。调色预览只改变显示，不写入原生颜色设置。字体通过原生比例缩放自定义文字，卡片宽高不随字号整体缩放。

首页只恢复 `is_user=false` 且非系统的助手问候，系统快捷消息不再重复显示。助手默认头像的读取同样排除系统消息。正文留白之前被更高优先级的基础规则覆盖，本批修正选择器，左右各留 18px；保留自然的正文行对齐。
