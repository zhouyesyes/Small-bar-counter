# 休息区和聊天阅读页

0.8.5 将已选的 The Lounge 和 C 版阅读排版接入真实页面，随扩展面板里的「吧台美化」开关启停。原字体和小手机保持原有设置。

默认页面保留宿主的最近聊天节点和打开、置顶、删除操作；新增搜索、常用角色、快捷入口以及就近弹出的菜单。菜单的「改名」只保存显示备注，以角色头像文件名识别，不改角色卡名、聊天文件名或发给模型的内容。隐藏和模糊仅影响休息区，隐藏的角色可通过「显示隐藏的角色」恢复。

聊天页的标题位于聊天滚动区。每条消息使用 62px 通栏头图、40px 头像和两侧 10px 的正文边距，没有卡片背景或边框。自己的头像在右侧，默认跟随朋友圈；对方默认跟随角色卡。群聊保留各消息的原角色头像。对话页仅展示这些共用图片，不提供单独更换入口。要换图，在角色卡或朋友圈原有入口修改，对话页同步跟随；以前的 `chatAppearance` 独立图片覆盖不再参与显示。

消息正文、原编辑按钮和切换回复节点留在原处。流式生成时只让宿主更新正文，不重建头图或第三方脚本内容。关闭美化会移除新增节点并恢复原页面。

验证：以 TauriTavern 2.4.0 的原消息模板和 welcomePanel 模板运行 Chromium 390px 检查，覆盖搜索、备注不改原名、常用角色、原生操作转发、左右头像、通栏头图、正文宽度、标题滚出视口、流式内容节点稳定、共用图片同步、忽略旧独立覆盖以及关闭恢复；另运行头像配置、音乐来源和主题回归测试。
